# NavigationBar

> **Storybook Group**: Atoms / Navigation Bars | **Figma Level**: Organism | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7407-2558)

## Overview

NavigationBar is the mobile bottom navigation bar for switching between the main product sections. It is built from the `SectionBar` atom and does not include the status bar or home indicator.

**Use this component when:**
- The user needs persistent navigation between the main app sections.
- The active section maps to the Figma `Section` variant.
- The navigation remains presentational and route changes are handled by the parent through `onNavigate`.

**Do not use this component when:**
- The UI needs one or two workflow actions. Use `ActionBar`.
- The page needs local tabs within a single view. Use a section navigation pattern instead.
- The component would need to own routing, storage, auth, or fetched state internally.

## Default Usage

<Canvas of={NavigationBarStories.MyLoan} />

```tsx
import { NavigationBar } from '@design-system/components';

<NavigationBar section="My Loan" onNavigate={(section) => navigate(section)} />
```

The default story uses Storybook-only state so clicking an item changes the selected section in the canvas. The component itself stays controlled by `section` and reports changes through `onNavigate`.
