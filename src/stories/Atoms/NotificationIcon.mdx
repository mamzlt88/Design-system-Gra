# NotificationIcon

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=2870-5575)

## Overview

NotificationIcon is a small visual marker for notification and card activity types. It helps people scan a list and quickly understand what kind of update they are seeing.

This page uses [Component Gallery's Icon reference](https://component.gallery/components/icon/) as a documentation guide. The visual meaning and variants come from the Gra Figma UI Kit.

**Use this component when:**
- A card or notification needs a quick visual category.
- The icon appears beside supporting text.
- The type comes from one of the Figma-defined activity meanings.

**Do not use this component when:**
- The icon is the only way to understand the message.
- The card needs an interactive control. Use a button instead.
- The activity type is not one of the approved options.

## Default Usage

<Canvas of={NotificationIconStories.RequestedLoan} />

```tsx
import { NotificationIcon } from '@design-system/components';

<NotificationIcon type="requestedLoan" label="Requested loan" />
```
