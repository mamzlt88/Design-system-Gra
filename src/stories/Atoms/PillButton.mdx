# PillButton

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=8363-4304)

## Overview

PillButton is a compact selectable button. Use it for filters, small tabs, or short choices where the selected state matters.

This page uses [Component Gallery's Button reference](https://component.gallery/components/button/) as a documentation guide. The visual styles and states come from the Gra Figma UI Kit.

**Use this component when:**
- A person needs to choose one small option.
- The label is short enough to stay readable inside a pill.
- The selected state needs to be visible.

**Do not use this component when:**
- The action is a primary page action. Use `Button`.
- The option needs a long explanation.
- The component is only decoration and does not trigger a choice or action.

## Default Usage

<Canvas of={PillButtonStories.Default} />

```tsx
import { PillButton } from '@design-system/components';

<PillButton label="Tab X" />
```

## States

Use `enabled` for the normal state, `selected` for the active option, and `pressed` to show the button while it is being activated.

## Interaction

Pill buttons should feel quick and lightweight. When they behave like filters or tabs, the selected pill should remain clear after the click.
