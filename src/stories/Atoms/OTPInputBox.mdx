# OTPInputBox

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7878-668)

## Overview

OTPInputBox renders one one-time-passcode digit slot. Use it as the primitive for OTP input patterns.

**Use this component when:**
- A one-time-passcode digit needs its own visual slot.
- The field state matches a Figma-defined OTP box state.
- A composed OTP input controls the value.

**Do not use this component when:**
- A full six-digit OTP field is needed. Use `OTPInput`.
- The field should accept long text.
- The state is not one of the sourced Figma states.

## Default Usage

<Canvas of={OTPInputBoxStories.Enabled} />

```tsx
import { OTPInputBox } from '@design-system/components';

<OTPInputBox state="filled" value="2" ariaLabel="One-time passcode digit 1" />
```
