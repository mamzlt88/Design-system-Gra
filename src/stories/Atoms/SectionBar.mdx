# SectionBar

> **Storybook Group**: Atoms / Navigation Bars | **Figma Source**: Section Nav Bar | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7752-2780)

## Overview

SectionBar is the atomic navigation item used inside `NavigationBar`. It owns the visual treatment for default, selected, badge, and pressed interaction feedback.

**Use this component when:**
- A navigation item needs an icon, visible label, and selected state.
- The item may need a small activity badge.
- The parent owns routing and passes click behavior through props.

**Do not use this component when:**
- The UI needs a full bottom navigation bar. Use `NavigationBar`.
- The user needs to trigger a workflow action. Use `ActionBar` or `Button`.
- The item would need to own routing, fetched data, storage, or auth state.

## Default Usage

<Canvas of={SectionBarStories.Default} />

```tsx
import { SectionBar } from '@design-system/components';

<SectionBar label="Payments" icon="payments" state="selected" />
```
