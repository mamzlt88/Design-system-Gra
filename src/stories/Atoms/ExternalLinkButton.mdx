# ExternalLinkButton

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=9182-7501)

## Overview

ExternalLinkButton opens a page outside the current app. Use it when the person is leaving the product or opening supporting information in another place.

## Default Usage

<Canvas of={ExternalLinkButtonStories.Medium} />

```tsx
import { ExternalLinkButton } from '@design-system/components';

<ExternalLinkButton label="External Link" href="https://example.com" />
```
