# NotificationBadge

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7509-2356)

## Overview

NotificationBadge marks unread or pending notification counts. Use the dot size when the interface only needs to show that something exists, and digit sizes when the count matters.

**Use this component when:**
- A notification, tab, or icon needs a compact unread marker.
- The badge is paired with a visible label, icon, or destination.
- The count is short enough to remain readable.

**Do not use this component when:**
- The value is a general status label. Use `StatusBadge`.
- The badge itself needs to be clicked.
- The number needs detailed formatting or explanatory text.

## Default Usage

<Canvas of={NotificationBadgeStories.Small} />

```tsx
import { NotificationBadge } from '@design-system/components';

<NotificationBadge size="singleDigit" value={3} label="3 notifications" />
```
