# ActionBar

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=8387-10564)

## Overview

Combines one or two footer actions.

**Use this component when:**
- The surrounding workflow matches the sourced Figma component purpose.
- The visible state maps to a documented Figma variant.
- The component can stay presentational and controlled by props.

**Do not use this component when:**
- The behavior would require fetching, routing, storage, auth, or submission logic inside the component.
- The required state is not represented by Figma evidence or explicit config.
- A more specific existing component covers the use case.

## Default Usage

<Canvas of={ActionBarStories.DualActions} />

```tsx
import { ActionBar } from '@design-system/components';

<ActionBar type="dualActions" primaryLabel="Continue" secondaryLabel="Back" />
```

The default stories use Storybook-only state so clicking either action shows the pressed feedback. The component itself stays controlled by `primaryState` and `secondaryState`.
