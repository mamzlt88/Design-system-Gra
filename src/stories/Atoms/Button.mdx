# Button

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=50-6188)

## Overview

Button is the main action control. Use it when a person needs to submit, confirm, continue, cancel, or trigger an action.

This page uses [Component Gallery's Button reference](https://component.gallery/components/button/) as a documentation guide, while the visual styles and variants come from the Gra Figma UI Kit.

**Use this component when:**
- The action changes something on the current page.
- The action submits, confirms, cancels, or continues a flow.
- The label can clearly say what will happen next.

**Do not use this component when:**
- The action is navigation-only. Use a link or `ExternalLinkButton`.
- The action only needs an icon. Use `IconButton`.
- The action is unclear without extra explanation. In that case, improve the label or add supporting context nearby.

## Default Usage

## Variants

Use variants to show action priority, theme, or layout. The primary filled button should be the clearest next step. Outlined and text buttons are better for secondary or quieter actions. Danger actions should be visually distinct and used only when the result is risky or destructive.

<Canvas of={ButtonStories.VariantExamples} />

## States

Every button should have clear pressed and disabled behavior. Disabled buttons should not be the only explanation for why an action is unavailable; add nearby helper text when the reason matters.

<Canvas of={ButtonStories.StateExamples} />

## Interaction

Buttons perform actions. They should not be used as links to another page. Use clear action labels such as "Continue", "Save", "Delete", or "Upload document" instead of generic labels like "OK".
