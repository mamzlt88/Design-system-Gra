# ColorIndicator

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=9097-6463)

## Overview

ColorIndicator is a small vertical color marker. Use it beside list rows, cards, or compact content where color helps people scan related status or category information.

**Use this component when:**
- A row or card needs a compact color marker.
- The color is paired with visible text or surrounding context.
- The marker should not be interactive.

**Do not use this component when:**
- The color is the only way to understand meaning.
- The pattern needs a full text badge. Use `StatusBadge`.
- The marker needs to be clicked. Use a button or link pattern.

## Default Usage

<Canvas of={ColorIndicatorStories.Red} />

```tsx
import { ColorIndicator } from '@design-system/components';

<ColorIndicator color="red" label="Late payment" />
```
