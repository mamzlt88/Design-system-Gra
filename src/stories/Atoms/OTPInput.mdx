# OTPInput

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7878-736)

## Overview

OTPInput composes six OTP input boxes with optional supporting text. Use it when a one-time passcode must be entered as separate digit slots.

**Use this component when:**
- The flow asks for a short one-time passcode.
- The value can be represented as a controlled string.
- Supporting text needs to appear below the boxes.

**Do not use this component when:**
- The input accepts normal free-form text.
- The code length or validation behavior is unknown.
- The component would need to fetch, verify, or submit the code itself.

## Default Usage

<Canvas of={OTPInputStories.Empty} />

```tsx
import { OTPInput } from '@design-system/components';

<OTPInput value="234567" showSupportingText={false} />
```
