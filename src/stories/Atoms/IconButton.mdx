# IconButton

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=91-4104)

## Overview

IconButton is a compact action button that uses only an icon. Use it for small repeated actions, close controls, and toolbars.

This page uses [Component Gallery's Button reference](https://component.gallery/components/button/) as a documentation guide, especially for icon-only button accessibility. The visual styles and variants still come from the Gra Figma UI Kit.

**Use this component when:**
- The action is already clear from context.
- Space is limited and a visible text label would make the layout noisy.
- The icon is familiar or repeated in a pattern the user can learn quickly.

**Do not use this component when:**
- The action is unfamiliar or high-risk.
- The action needs visible text to be understood.
- The icon could mean more than one thing without a label nearby.

## Default Usage

<Canvas of={IconButtonStories.Default} />

```tsx
import { IconButton } from '@design-system/components';

<IconButton ariaLabel="Add item" icon="plus" />
```

## Variants

Use variants to match the importance of the action. A filled icon button attracts more attention, while outlined and tonal icon buttons are better for repeated or secondary actions.

<Canvas of={IconButtonStories.AllVariants} />

## States

Icon buttons must keep the same size across pressed and disabled states so toolbars and dense layouts do not shift.

<Canvas of={IconButtonStories.StateExamples} />

## Interaction

Icon buttons perform actions, not navigation. When the action is destructive, use a warning style only when the result is clear and confirmed somewhere in the flow.
