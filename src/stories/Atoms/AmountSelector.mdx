# AmountSelector

> **Atomic Level**: Atom | **Family**: Input Components | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=8273-7829)

## Overview

AmountSelector is an input stepper for increasing or decreasing an amount. Use it when a person needs to adjust a visible value in small steps.

## Default Usage

<Canvas of={AmountSelectorStories.Initial} />

```tsx
import { AmountSelector } from '@design-system/components';

<AmountSelector value="Value" />
```

## Interaction

Use the interactive stepper to click the plus and minus buttons and see the value change. The pressed state appears briefly on the control that was clicked.
