# AmountSelector

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=8273-7829)

## Overview

AmountSelector shows a selected amount or a starting placeholder. Use it when a person needs to choose or confirm a value.

## Default Usage

<Canvas of={AmountSelectorStories.Initial} />

```tsx
import { AmountSelector } from '@design-system/components';

<AmountSelector value="Value" />
```

## Accessibility

| Expectation | Implementation |
|-------------|----------------|
| Role | Native `button` |
| Accessible name | `Select amount` or selected amount text |
| Keyboard | `Tab` focuses, `Enter` and `Space` activate |
| Disabled | Native `disabled` attribute |
