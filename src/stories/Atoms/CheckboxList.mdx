# CheckboxList

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7673-5287)

## Overview

Stacks sourced checkbox rows from item data with optional scroll indicators and text field.

**Use this component when:**
- The surrounding workflow matches the sourced Figma component purpose.
- The visible state maps to a documented Figma variant.
- The component can stay presentational and controlled by props.

**Do not use this component when:**
- The behavior would require fetching, routing, storage, auth, or submission logic inside the component.
- The required state is not represented by Figma evidence or explicit config.
- A more specific existing component covers the use case.

## Default Usage

<Canvas of={CheckboxListStories.DataDriven} />

```tsx
import { CheckboxList } from '@design-system/components';

<CheckboxList
  items={[
    { id: 'loan-purpose', label: 'Loan purpose', checked: true },
    { id: 'business-plan', label: 'Business plan' },
  ]}
  onItemChange={(id, checked) => updateItem(id, checked)}
/>
```
