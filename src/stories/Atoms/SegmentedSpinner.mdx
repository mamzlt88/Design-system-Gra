# SegmentedSpinner

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=9761-597)

## Overview

SegmentedSpinner communicates an indeterminate loading state using eight opacity-weighted segments. Use it where the segmented loader is the intended visual reference.

**Use this component when:**
- A compact loading indicator should use the segmented spinner pattern.
- The loading state is indeterminate.
- A parent or external controller chooses the active rotation frame.

**Do not use this component when:**
- The progress value is determinate and should show a percentage.
- The surrounding UI needs a circular arc spinner. Use `CircularSpinner`.
- The spinner should own application state or timing.

## Default Usage

<Canvas of={SegmentedSpinnerStories.RotationOne} />

```tsx
import { SegmentedSpinner } from '@design-system/components';

<SegmentedSpinner label="Loading transfers" />
```
