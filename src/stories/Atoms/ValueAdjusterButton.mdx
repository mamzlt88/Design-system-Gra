# ValueAdjusterButton

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=8510-11062)

## Overview

ValueAdjusterButton is a compact plus or minus button. Use it when a person needs to increase or decrease a value one step at a time.

This page uses [Component Gallery's Button reference](https://component.gallery/components/button/) as a documentation guide, especially for icon-only button labeling. The visual styles and states come from the Gra Figma UI Kit.

**Use this component when:**
- A value changes by one step at a time.
- The plus or minus meaning is obvious in the surrounding layout.
- The control appears beside a visible value.

**Do not use this component when:**
- A person needs to type an exact number. Use an input instead.
- The value change is large or hard to undo.
- The icon would be unclear without nearby value text.

## Default Usage

<Canvas of={ValueAdjusterButtonStories.Decrease} />

```tsx
import { ValueAdjusterButton } from '@design-system/components';

<ValueAdjusterButton adjustment="decrease" ariaLabel="Decrease value" />
```
