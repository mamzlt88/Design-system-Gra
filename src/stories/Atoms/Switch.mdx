# Switch

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7521-6965)

## Overview

Switch controls a binary setting. Use it when a setting can be turned on or off immediately.

**Use this component when:**
- A user can enable or disable a setting.
- The setting has clear on and off states.
- The switch label is provided by surrounding text or `ariaLabel`.

**Do not use this component when:**
- The action submits a form or starts a task. Use a button.
- The choice is one of many options. Use radio buttons or a selector.
- The setting needs confirmation before it changes.

## Default Usage

<Canvas of={SwitchStories.Off} />

```tsx
import { Switch } from '@design-system/components';

<Switch state="on" ariaLabel="Enable notifications" />
```
