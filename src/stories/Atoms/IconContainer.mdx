# IconContainer

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=9084-6053)

## Overview

IconContainer is a small colored holder for an icon. It helps people scan a screen by pairing a simple visual marker with nearby text.

This pass uses the saved Figma snapshot for the container shape, size, radius, and color fills. Please review the final icon choice against the design.

**Use this component when:**
- A card, list item, or status row needs a small visual marker.
- The icon is supportive, and nearby text explains the meaning.
- The color and style match one of the Figma-defined options.

**Do not use this component when:**
- The icon should trigger an action. Use `IconButton` instead.
- The icon is the only way the person understands the content.
- You need a large illustration or a notification-specific graphic.

## Default Usage

<Canvas of={IconContainerStories.Default} />

