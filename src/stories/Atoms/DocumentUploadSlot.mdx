# DocumentUploadSlot

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=9304-2207)

## Overview

DocumentUploadSlot is the place where a person can add or review a document. Use it when a form asks for a file, proof, or supporting document.

## Default Usage

<Canvas of={DocumentUploadSlotStories.Default} />

```tsx
import { DocumentUploadSlot } from '@design-system/components';

<DocumentUploadSlot instructionText="Upload proof of identity" requirement="required" />
```
