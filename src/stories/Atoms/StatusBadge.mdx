# StatusBadge

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7483-6154)

## Overview

StatusBadge communicates a compact status label. Use it when the status needs visible text and an approved status color treatment.

**Use this component when:**
- A row, card, or detail area needs a short visible status.
- The status matches one of the Figma-defined meanings.
- The text can stay short and scannable.

**Do not use this component when:**
- The status needs a long explanation.
- The visual should only be an unread count. Use `NotificationBadge`.
- The badge needs to trigger an action.

## Default Usage

<Canvas of={StatusBadgeStories.Informative} />

```tsx
import { StatusBadge } from '@design-system/components';

<StatusBadge status="success" label="STATUS" />
```
