# UserAvatar

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=1640-11011)

## Overview

Renders a circular user image when a source is available, then falls back to initials from the user's first and last name.

**Use this component when:**
- You have a user photo, profile image, or Figma avatar variant to show.
- You need a fallback made from the user's first and last initials.
- The component can stay presentational and controlled by props.

**Do not use this component when:**
- The behavior would require fetching, routing, storage, auth, or submission logic inside the component.
- The required state is not represented by Figma evidence or explicit config.
- A more specific existing component covers the use case.

## Default Usage

<Canvas of={UserAvatarStories.Avatar} />

```tsx
import { UserAvatar } from '@design-system/components';

<UserAvatar size="medium" imageSrc={user.profileImageUrl} name="Ana Silva" />
<UserAvatar size="medium" type="initials" name="Ana Silva" />
```
