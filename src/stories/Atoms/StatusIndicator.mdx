# StatusIndicator

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7873-607)

## Overview

StatusIndicator communicates a compact list or step status. Use it when a small circular status marker is enough and surrounding text already explains the item.

**Use this component when:**
- A list, step, or information row needs a compact status marker.
- The status is one of the Figma-defined values.
- The marker is paired with visible row or step text.

**Do not use this component when:**
- The status needs visible label text inside the component. Use `StatusBadge`.
- The indicator needs to trigger an action.
- The icon needs a custom source that has not been mapped.

## Default Usage

<Canvas of={StatusIndicatorStories.Completed} />

```tsx
import { StatusIndicator } from '@design-system/components';

<StatusIndicator status="completed" label="Completed status" />
```
