# CircularSpinner

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=9476-242)

## Overview

CircularSpinner communicates an indeterminate loading state. Use it where a compact circular loader is needed and the surrounding UI already explains what is loading.

**Use this component when:**
- A component, row, panel, or page region is waiting for work to complete.
- The loading state is indeterminate.
- A compact circular visual is preferred over a segmented loader.

**Do not use this component when:**
- The progress value is determinate and should show a percentage.
- The loading state needs a text message as the primary content.
- The UI needs user input while loading.

## Default Usage

<Canvas of={CircularSpinnerStories.Small} />

```tsx
import { CircularSpinner } from '@design-system/components';

<CircularSpinner size="small" label="Loading transactions" />
```
