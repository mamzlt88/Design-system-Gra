# LanguageImage

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7878-11296)

## Overview

LanguageImage is a small visual marker for language dropdowns. It helps people recognize whether the current language option is English or Spanish.

This is a first-pass component from the source catalog. Figma live context was not available because the Figma MCP tool limit was reached, so the exact visual styling should be reviewed against Figma before approval.

**Use this component when:**
- A language dropdown needs a compact visual language marker.
- The option is English or Spanish.
- The language name is shown nearby.

**Do not use this component when:**
- The user needs to choose a language by image alone.
- The language list includes more languages that are not defined in Figma yet.
- The control itself needs to open a menu. Use a dropdown component around it.

## Default Usage

<Canvas of={LanguageImageStories.English} />

```tsx
import { LanguageImage } from '@design-system/components';

<LanguageImage language="english" />
```
