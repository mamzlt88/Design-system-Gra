# CheckboxRadioButton

> **Atomic Level**: Atom | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7521-6940)

## Overview

CheckboxRadioButton is the shared control set for radio choices and checkbox choices. Use it when a person needs to select one option, select a checkbox, or confirm a choice.

This page uses Component Gallery-style documentation guidance for form controls. The available states and types come from the Gra Figma UI Kit. Figma live context was not available during this pass because the Figma MCP tool limit was reached, so visual details should be reviewed by a designer.

**Use this component when:**
- A person needs to choose or confirm something.
- The control needs to match one of the Figma types.
- The option can be explained with a short label and optional supportive text.

**Do not use this component when:**
- The choice triggers a page-level action. Use a button.
- The option needs a long explanation.
- The design needs a full list pattern instead of a single control.

## Default Usage

<Canvas of={CheckboxRadioButtonStories.RadioText} />

```tsx
import { CheckboxRadioButton } from '@design-system/components';

<CheckboxRadioButton type="radioText" itemText="Item" />
```

## Types
