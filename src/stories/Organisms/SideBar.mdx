# SideBar

> **Storybook Group**: Classic Components / Navigation | **Figma SideBar**: [View](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=9229-6716) | **Figma Side Bar Item List**: [View](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7878-9389)

## Overview

SideBar is the mobile drawer navigation pattern from the Figma component. It combines the profile header, grouped navigation rows, accordion row, footer row, and overlay area into one component.

`SideBarItem` remains exported for code consumers, but it is documented here because it is the internal row primitive used to build the SideBar groups.

## Default Usage

<Canvas of={SideBarStories.Default} />

```tsx
import { SideBar } from '@design-system/components';

<SideBar name="Full Name" detailLabel="Label 1" detailValue="Value 1" />
```
