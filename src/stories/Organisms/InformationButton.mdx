# InformationButton

> **Storybook Group**: Organisms / Buttons | **Figma Level**: Organism | **Status**: Draft | **Figma**: [View in Figma](https://www.figma.com/design/LuOSourQp644YKhg0MrCE0/UI_Kit_-In-progress-?node-id=7521-7432)

## Overview

InformationButton is a compact helper action that can reveal supporting information through a sourced tooltip-open state. It composes the existing `Icon` and `Tooltip` primitives while keeping the open state controlled by props.

**Use this component when:**
- A field, step, or section needs a short explanation available on demand.
- The visible state maps to `Enabled`, `Pressed`, or `Tooltip Open`.
- The parent owns whether the tooltip is open and handles any analytics or app behavior.

**Do not use this component when:**
- The content is primary page copy that should always be visible.
- The interaction needs routing, fetching, storage, or permission logic inside the component.
- The UI needs a full callout card or alert message instead of a compact helper action.

## Default Usage

<Canvas of={InformationButtonStories.Enabled} />

```tsx
import { InformationButton } from '@design-system/components';

<InformationButton
  label="Why is this needed?"
  state={isOpen ? 'tooltipOpen' : 'enabled'}
  tooltipText="This information helps explain why the user is being asked for this step."
  onClick={() => setIsOpen((open) => !open)}
/>
```

The default Storybook canvas uses story-only state so clicking the button toggles the tooltip-open state. The component itself remains controlled by `state`.
